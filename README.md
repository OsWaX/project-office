# Демонстрационная версия портала Проектного офиса

Один HTML-файл — [`demo/index.html`](demo/index.html) — воспроизводит портал Проектного
офиса по текстильной промышленности (`OsWaX/uz-textile-invest`, ветка
`claude/uz-textile-invest-website-t4gish`) целиком в браузере, без Node.js и SQLite.

Опубликован как Artifact в Claude: <https://claude.ai/code/artifact/ffef0867-3a82-4c48-b284-6ec103f6ab53>

## Что перенесено из исходного проекта

| Источник | Что взято |
|---|---|
| `public/css/app.css` | Система стилей целиком (620 строк), без изменений; в конце файла добавлен блок стилей для выбора роли, переключателя ролей и карты регионов |
| `server/rbac.js` | Матрица прав `PERMISSIONS`, функции `can`, `isOwnRecord` |
| `scripts/seed.js` | 11 сотрудников, 15 компаний, 15 проектов, дорожные карты, 5 визитов с программой встреч, комментарии, заявка на исправление |
| `server/reference.js`, `server/data/geo.js` | Справочники статусов, типов записей, отраслей, валют, курсов; 9 регионов и страны |
| `public/js/views/*` | Логика экранов: дашборд, реестр, карточка проекта, компании, визиты, доска, календарь, отчёты, заявки, журнал аудита |
| `public/js/ui.js`, `charts.js` | Помощники разметки, форматирование дат и сумм, кольцевая диаграмма, полосы, лента дорожной карты |

## Экраны

Вход с выбором роли в один клик, переключатель роли в верхней панели, дашборд,
реестр и карточка проекта с дорожной картой и лентой времени, компании, визиты с
программой встреч по дням, доска проектов с переносом карточек, календарь,
отчёты, заявки на исправление, журнал аудита.

## Права доступа

Матрица прав из ТЗ работает по-настоящему, а не только скрывает кнопки:

- **Администратор** — изменяет и удаляет записи, решает по заявкам, видит журнал аудита.
- **Проектный менеджер** — создаёт записи и комментирует; меняет статусы и отмечает
  этапы **только по своим** записям; изменить созданную запись не может — вместо
  кнопки «Изменить» доступна «Запросить исправление». Заявку рассматривает
  администратор: при одобрении значение применяется к записи, и это попадает в журнал аудита.
- **Наблюдатель** — только просмотр и выгрузка отчётов.

## Данные и выгрузка

Состояние хранится в `localStorage` и переживает перезагрузку; кнопка «Сбросить
демо-данные» возвращает исходный набор. Выгрузка — CSV (UTF-8 с BOM, разделитель
«;», открывается в Excel без настройки) через возможность artifact `downloads`;
если возможность недоступна, кнопки выгрузки отключаются с пояснением.
