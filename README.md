# Портал Проектного офиса — рабочая версия

Один HTML-файл — [`portal/index.html`](portal/index.html) — работающая система учёта
проектов Проектного офиса по текстильной промышленности. Развёрнута как Artifact:
<https://claude.ai/code/artifact/ffef0867-3a82-4c48-b284-6ec103f6ab53>

Исходник: `OsWaX/uz-textile-invest`, ветка `claude/uz-textile-invest-website-t4gish`
(Node.js + SQLite), включая Дополнение № 1 к ТЗ.

## Чем это отличается от демонстрации

| | Демонстрация | Рабочая версия |
|---|---|---|
| Данные | localStorage, у каждого свои | в самом документе, общие для всех |
| Сохранение | в браузере | публикация новой версии (`artifact.publish`) |
| Вход | выбор роли в один клик | код доступа, PBKDF2 с солью |
| Учётные записи | одиннадцать вымышленных | заводит администратор |
| Наполнение | 15 проектов, 15 компаний | пустая система |

Данные лежат в теге `<script type="application/json" id="app-state">`. При каждом
изменении документ пересобирается из данных и собственного исходного кода и
публикуется заново — все открытые вкладки переходят на новую версию. Проверено,
что код воспроизводит себя между поколениями дословно.

## Разделы

Дашборд, реестр проектов, карточка проекта с дорожной картой и лентой времени,
компании, визиты с программой встреч по дням, доска проектов, календарь, отчёты,
заявки на исправление. Администрирование: пользователи, конструктор форм,
справочники, настройки, журнал аудита, корзина.

## Права доступа (раздел 2.2 ТЗ)

- **Администратор** — изменяет и удаляет записи, решает по заявкам, ведёт
  справочники, пользователей и настройки, видит журнал аудита и корзину.
- **Проектный менеджер** — создаёт записи и комментирует; меняет статусы и
  отмечает этапы только по своим записям; изменить созданную запись не может —
  подаёт заявку на исправление. Одобрение применяет значение и попадает в журнал.
- **Наблюдатель** — просмотр и выгрузки.

## Дополнение № 1 к ТЗ

- **P-16, местные партнёры** — узбекская сторона проекта: несколько организаций
  с ролью в проекте. Своя организация и иностранный партнёр не совпадают.
- **P-17, регионы реализации** — 14 регионов страны; город или район обязателен,
  объём в регионе необязателен. Заполняется у инвестиционных проектов;
  переключатель в настройках распространяет поле на экспортные записи.
- Дашборд: блок «Реализация в Узбекистане» со схематической картой,
  показателем охвата регионов и объёмом, не распределённым по площадкам.

## Ограничения, о которых нужно знать

- **Хеши кодов доступа лежат в исходном коде страницы.** Это разграничивает
  работу сотрудников между собой, но не защищает данные от того, у кого есть
  ссылка. Доступом управляйте через доступ к артефакту.
- **Размещение.** Раздел 11 ТЗ требует серверов в Республике Узбекистан.
  Артефакт размещён вне страны — для боевой эксплуатации разворачивайте
  Node.js + SQLite версию из исходного репозитория.
- Одновременная запись двумя сотрудниками: чьё сохранение пришло вторым,
  получает предупреждение и повторяет действие.
- Вложения файлов не поддерживаются: среда не даёт хранилища файлов.

## Проверка

`portal/tests/` — стенд, повторяющий поведение артефакта (публикация, отказ в
записи, конфликт, ограничение частоты), и 57 браузерных проверок: вход и
хеширование, общие данные, права трёх ролей, полный цикл заявки, справочники,
конструктор форм и голосования, корзина, выгрузки, тёмная тема и телефон.
