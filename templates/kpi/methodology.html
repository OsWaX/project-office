{% translate "How KPI is calculated" %}

{% translate "Every employee's KPI is calculated once a month from the tasks in this portal. The rules are the same for everyone and every number can be checked on the employee's KPI page." %}

1. {% translate "Which tasks count" %}

  • {% translate "A task belongs to the month in which its deadline falls." %}
  • {% translate "Cancelled tasks are not counted." %}
  • {% translate "A task is assessed when it has been accepted by the manager, or when its deadline has passed and it has not been handed in (then it counts as not done)." %}
  • {% translate "Tasks handed in and waiting for the manager's review are not counted until they are reviewed, so a slow review never lowers the employee's score." %}
  • {% translate "Timeliness is judged by the date the executor handed the work in, not by the date the manager accepted it." %}

2. {% translate "Task weight by complexity" %}

{% translate "Harder tasks weigh more in every component:" %}

{% translate "Simple" %}{{ s.points_simple }}
{% translate "Medium" %}{{ s.points_medium }}
{% translate "Complex" %}{{ s.points_complex }}
{% translate "Very complex" %}{{ s.points_very_complex }}

3. {% translate "Four components (each from 0 to 100)" %}

  1. {% translate "Execution" %} ({{ s.weight_completion }}%) — {% translate "points of completed tasks ÷ points of all assessed tasks." %}
  2. {% translate "Timeliness" %} ({{ s.weight_timeliness }}%) — {% translate "points of tasks handed in by the deadline ÷ points of all assessed tasks." %}
  3. {% translate "Quality" %} ({{ s.weight_quality }}%) — {% translate "the manager's average rating (1–5) of completed tasks, weighted by points, as a share of 5." %}
  4. {% translate "Workload" %} ({{ s.weight_workload }}%) — {% blocktranslate with norm=s.default_monthly_norm %}points of completed tasks ÷ monthly norm (default {{ norm }} points, can be set per person), at most 100. During the current month the norm is reduced in proportion to the days that have passed.{% endblocktranslate %}

4. {% translate "Final score" %}

{% translate "Base score" %} = {{ s.weight_completion }}% × {% translate "Execution" %} + {{ s.weight_timeliness }}% × {% translate "Timeliness" %} + {{ s.weight_quality }}% × {% translate "Quality" %} + {{ s.weight_workload }}% × {% translate "Workload" %}
{% translate "KPI" %} = {% translate "Base score" %} + {% translate "manager adjustments" %} ({% translate "from 0 to 100" %})

{% blocktranslate with m=s.max_adjustment %}A manager may add a bonus or penalty of up to ±{{ m }} points per entry with a written reason, for work that is not in the portal or for discipline issues. The reason is visible to the employee.{% endblocktranslate %}

{% translate "If a component cannot be measured (for example, nothing was completed, so there is nothing to rate), its weight is shared among the other components." %}

5. {% translate "Grades" %}

  • {{ grade_labels.excellent }} — {% blocktranslate with t=s.grade_excellent %}{{ t }} and above{% endblocktranslate %}
  • {{ grade_labels.good }} — {% blocktranslate with t=s.grade_good %}{{ t }} and above{% endblocktranslate %}
  • {{ grade_labels.satisfactory }} — {% blocktranslate with t=s.grade_satisfactory %}{{ t }} and above{% endblocktranslate %}
  • {{ grade_labels.unsatisfactory }} — {% blocktranslate with t=s.grade_satisfactory %}below {{ t }}{% endblocktranslate %}

6. {% translate "Closing the month" %}

{% translate "After the month ends the manager reviews the remaining tasks and finalises the month. Finalised results are frozen: later edits to tasks or settings do not change them. A finalised month can be reopened if a correction is needed." %}

{% translate "Example" %}

{% translate "An employee had 4 tasks due in the month: two medium (2 points each), one complex (3) and one simple (1) — 8 points in total. The complex task was handed in a day late, the simple one was not done. Ratings: 5, 4 and 4." %}

  • {% translate "Execution = 7 ÷ 8 = 87.5" %}
  • {% translate "Timeliness = 4 ÷ 8 = 50" %}
  • {% translate "Quality = (2×5 + 2×4 + 3×4) ÷ 7 = 4.29 of 5 = 85.7" %}
  • {% translate "Workload with a norm of 20 = 7 ÷ 20 = 35" %}
  • {% translate "KPI = 0.35×87.5 + 0.25×50 + 0.25×85.7 + 0.15×35 = 69.8 (Satisfactory) with the default weights" %}
